# CodeAlpha Java Application Using Gradle

## Project Overview
This project is a simple Java application created using Gradle as part of the CodeAlpha DevOps Internship.

## Technologies Used
- Java
- Gradle
- JUnit Jupiter

## Features
- Runs a Java application using Gradle.
- Uses Gradle to build and test the project.
- Includes Gradle Wrapper files for easier execution.

## How to Run

Build the project:

```bash
gradlew.bat build
```

Run the application:

```bash
gradlew.bat run
```
